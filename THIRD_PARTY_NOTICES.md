# Third-party components and assets

The application uses Three.js and pixiv three-vrm (MIT), FastAPI (MIT), faster-whisper (MIT), CTranslate2 (MIT), and edge-tts (LGPL-3.0). See each installed package's license for complete terms and transitive dependencies. Package versions are recorded in `package-lock.json` and `requirements.lock.txt`.

The ChatVRM source clone is retained solely as a development reference at `references/ChatVRM`. Its MIT license, copyright (c) 2023 pixiv Inc., remains in that directory. No ChatVRM character, image, or animation asset has been copied into the running application.

The VRM file was exported from the user's selected VRoid Studio sample character. Original sample metadata shown before the user's export edits identified **AvatarSample_S / pixiv VRoid Project**. The exported file is named **mamadv1**, author field **mgi301**. These are recorded as observed metadata, not a determination of original asset authorship or a transfer of rights.

The exported VRM metadata specifies the VRM Public License 1.0, author-only avatar permission, personal/nonprofit commercial-use category, no redistribution, and no modification. The original export is kept in the project and the runtime uses a local copy. Rig poses/expressions are applied at runtime. No avatar has been uploaded or published. Check the original VRoid sample/outfit terms before any future distribution.
